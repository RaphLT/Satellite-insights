Appendix

Vibe-coding prototype: prompt log, limits and sources

This site, the car-counter tool and the supporting prototypes were built by vibe-coding: an AI assistant wrote the code and the pages, and we directed it and checked the results against hand labels and by eye. The log below lists every prompt we sent, in order, with the tool and the date.

  • Main prototype (question A): Car Counter from Above, the in-browser car counter
  • Supporting work: 1. How a data signal loses value · 2. Can a student rebuild the car counter? · 3. Training our own model · 4. Englos over time (unfinished)
  • Code: github.com/RaphLT/Satellite-insights
  • Tools: Claude (Anthropic), model Claude Opus 5.5, in the Claude app (claude.ai) and in Claude Code; the log says which tool each prompt went to.
